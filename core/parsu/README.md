# enki-parsu

Hardware profiling, device discovery, and JIT compilation synthesis engine for the Enki heterogeneous compute runtime.
Part of the [Enki](https://github.com/enkiruntime/enki) ecosystem.

## Features
- Hardware Profile Discovery: physical device capability querying (Subgroups, Cooperative Matrix, Push Constants)
- Automated Toolchain Bootstrap: Seamless background resolution and integrity verification of native compilation backends
- Anutu Cache Baking: Fast binary artifact serialization for cold-start pipeline reuse
